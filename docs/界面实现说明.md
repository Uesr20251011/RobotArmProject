# 界面实现说明（RobotArmUI）

本文记录界面工作流在初始化骨架上完成的实现，对应分支 `feature/ui-interaction-drawing-animation`。
原始接口与槽函数名保持《面向对象作业设计.md》中的约定，界面只消费 Common / Kinematics / Trajectory
三个 DLL 的现有导出函数，没有修改任何库接口。

## 文件清单

| 文件 | 作用 |
| --- | --- |
| `RobotArmUI/MainWindow.ui` | Designer 主窗口：左侧参数与操作面板，右侧仿真视图 |
| `RobotArmUI/MainWindow.h` / `.cpp` | 窗口逻辑：参数设置、正逆解、轨迹规划、动画播放 |
| `RobotArmUI/ArmCanvas.h` / `.cpp` | 自绘控件：网格、工作空间、机械臂、轨迹、目标点、角度弧 |
| `RobotArmUI/RobotArmUI.pro` | 把 `ArmCanvas` 加入 `SOURCES` / `HEADERS` |

`RobotArmUI.vcxproj` 由 qmake 生成、不入库；新增源文件后重新执行 `scripts/Generate-VS.ps1` 即可同步。

## 界面布局

```text
┌──────────── 左侧 QScrollArea（控制面板）────────────┬────────────── 右侧仿真视图 ──────────────┐
│ ① 连杆与关节参数：L1 / L2、q1 / q2（角度）           │                                          │
│    应用参数、正运动学计算                            │   ArmCanvas：坐标网格、工作空间圆、      │
│ ② 逆运动学：末端目标 X / Y、肘上 / 肘下              │   当前机械臂、轨迹曲线、当前帧高亮、      │
│    逆运动学求解                                      │   目标点标记、q1 / q2 角度弧、图例        │
│ ③ 轨迹规划：目标关节角、运动时间、采样间隔           │                                          │
│    关节空间规划、笛卡尔直线规划                      │                                          │
│ ④ 轨迹动画：播放 / 暂停 / 下一帧 / 回到起点          │                                          │
│    播放速度、帧进度条、帧计数、轨迹摘要              │                                          │
│ 当前机械臂状态：长度、角度（rad + °）、肘关节、末端   │                                          │
└──────────────────────────────────────────────────────┴──────────────────────────────────────────┘
状态栏：每一步操作的结果提示，失败时给出具体原因
```

角度在界面上以「度」输入和显示，调用 DLL 前统一换算为弧度（`qDegreesToRadians`），
状态区同时显示弧度与角度，避免与接口约定混淆。长度、坐标使用与算法库一致的长度单位。
窗口初始尺寸为 1360×940，但会在小屏幕上自动限制到可用桌面范围；最小可缩到 1000×640，
左侧面板放在 `QScrollArea` 中，窗口变小时可滚动，右侧仿真视图自动缩放。

## 交互与槽函数

| 槽函数 | 行为 |
| --- | --- |
| `OnSetParameters()` | 读取 L1 / L2 / q1 / q2，检查长度为正后 `arm.SetPara(length, angle)`，停止动画并清空旧轨迹 |
| `OnForwardSolve()` | 调用 Kinematics 的 `ForwardSolve`，再用三参数 `SetPara` 把显式位置写回公共状态，清空旧轨迹 |
| `OnInverseSolve()` | 先停止动画；用目标点与肘部构型调用 `InverseSolve`，按 `IKStatus` 提示成功 / 长度无效 / 超出工作空间 / 两种奇异位形。成功时应用角度并清空旧轨迹，失败时保持机械臂与旧轨迹不变并暂停动画 |
| `OnPlanJoint()` | 先停止动画，校验时间参数与「连杆长度已应用」，再调用 `planner.PlanJoint(...)`；结果为空或含非有限数值视为失败并清空轨迹 |
| `OnPlanCartesian()` | 同上，使用②中的末端目标与肘部构型；目标不可达时由逆解拒绝并提示失败 |
| `OnPlay()` / `OnPause()` | 启动 / 停止 `QTimer` 播放；播放到末帧后再次播放会提示并从头重播 |
| `OnNextFrame()` | 定时器超时与「下一帧」按钮共用；显示末帧后立即停止定时器并提示播放结束 |
| `OnResetAnimation()` | 回到轨迹起点（新增，便于演示） |
| `OnSeekFrame(int)` | 拖动进度条定位到任意帧（新增） |

辅助函数：`UpdateDisplay()` 刷新状态区并重绘，`DrawRobot()` / `DrawTrajectory()` 把机械臂状态与
轨迹交给 `ArmCanvas` 绘制，`ApplyFrame()` 用轨迹点的关节角更新 `RobotArm`（位置由 Common DLL
内部重新正解得到，保证显示姿态物理一致），`UpdateFrameControls()` 同步帧计数、进度条和按钮可用性。

## 绘制实现（ArmCanvas）

- 视图自动取景：范围 = max(两连杆总长 × 1.1, 机械臂各点、轨迹各点、目标点的最大坐标)，等比缩放，
  世界原点即基座关节，y 轴向上。窗口缩放时自动重算，不改变机械臂状态；轨迹范围在载入轨迹时
  缓存一次，动画播放期间不重复扫描整条轨迹。
- 网格按 1 / 2 / 5 × 10ⁿ 取间距，保证约 60 px 一格，并绘制 x / y 轴与刻度；虚线圆为最大可达半径。
- 机械臂：连杆 1 蓝色、连杆 2 橙色、基座 / 肘关节深色圆点、末端执行器红色圆点；
  用圆弧与 `q1` / `q2` 标注两个关节角（`q2` 为相对第一根连杆的转角）。
- 轨迹：末端路径为青色实线、肘关节路径为浅蓝虚线，起点空心圆、终点方块，当前动画帧用高亮光点标出。
- 目标点：品红十字圆环并标注坐标，便于对照逆解 / 笛卡尔规划结果。
- 左上信息板显示连杆长度、当前角度、末端坐标、网格单位与最大可达半径；右上图例；半透明白底保证
  文字在网格与小窗口下清晰。

## 动画实现

1. 规划成功时记录采样间隔 `playbackTimeStep`，`trajectory` 直接作为规划器输出容器（满足「失败清空结果」约定）。
2. 播放定时器间隔 = `采样间隔 × 1000 / 播放速度倍率`，实际限制在 5 ms ~ 2000 ms；播放速度支持
   0.5× / 1× / 2× / 4×（默认 20 ms 采样时 4× 为 5 ms，1 s 采样时 0.5× 为 2000 ms）。
3. 每次超时把下一帧的关节角写入 `RobotArm`，刷新状态区与画布；进度条、帧计数同步更新，
   手动拖动进度条会先暂停再定位。显示末帧后立即停止定时器。
4. 播放期间参数输入组禁用（防止逐帧刷新覆盖尚未应用的输入），暂停 / 结束后恢复可编辑；
   播放 / 暂停按钮随播放状态互斥启用。
5. 轨迹为空（含规划失败）时播放 / 暂停 / 下一帧 / 回到起点全部禁用；播放到末帧自动停止并提示。
6. 点击参数、正运动学、逆运动学或规划按钮都会先停止当前动画；任何失败路径（逆解失败、
   时间参数无效、规划器返回失败）都不会让机械臂继续运动，也不会保留旧轨迹（逆解失败除外，
   此时机械臂本身未变化，保留旧轨迹用于对照）。

## 与其他模块的边界

- 不修改 `Common/`、`Kinematics/`、`Trajectory/` 的源码和接口，不新增 DLL 导出。
- 轨迹规划当前仍是失败骨架时，两个规划按钮会原样提示失败，不会伪造轨迹；等轨迹负责人实现后
  同一界面无需改动即可播放真实轨迹（本地用临时规划器验证过完整动画链路，临时实现未提交）。
- 失败语义遵循架构约定：逆解失败不覆盖输出角度，规划失败清空轨迹，规划过程不修改 `RobotArm`。
- 规划前检查界面中的连杆长度已经应用到机械臂，避免逆解 / 规划使用不同几何；规划结果会检查
  所有时间、角度、坐标均为有限数值，防止异常数据进入绘制和机械臂状态。

## 已知限制

- 仿真视图固定为俯视二维平面视图，未提供缩放 / 平移交互；需要时可在 `ArmCanvas` 上增加鼠标事件。
- 轨迹点的位置由规划器给出、机械臂姿态由关节角正解得到；若规划器输出自相矛盾，视图会显示两者的差异。
- 极端的采样间隔下播放速度倍率会受 5 ms / 2000 ms 帧间隔下限、上限影响，状态栏会显示实际帧间隔。
- 界面文字目前为中文硬编码，未接入 Qt Linguist 翻译文件。
